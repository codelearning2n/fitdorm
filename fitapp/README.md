# FitDorm — วิธีติดตั้งลงมือถือ

PWA ต้องเสิร์ฟผ่าน **https** ถึงจะ "เพิ่มลงหน้าจอโฮม" ได้ (เปิดไฟล์ `file://` ตรงๆ service worker ไม่ทำงาน) — เลือกวิธีใดวิธีหนึ่ง

## วิธีที่ 1: GitHub Pages (ฟรี ถาวร แนะนำ)
1. สร้าง repo ใหม่บน github.com (public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (index.html, manifest.json, service-worker.js, icon-192.png, icon-512.png)
3. Settings → Pages → Source เลือก `main` / root → Save
4. รอ ~1 นาที ได้ลิงก์ `https://<user>.github.io/<repo>/`
5. เปิดลิงก์ในมือถือ → เมนูเบราว์เซอร์ → "เพิ่มลงในหน้าจอหลัก / Add to Home Screen"

## วิธีที่ 2: ทดสอบในคอมก่อน (localhost)
```bash
cd fitapp
python3 -m http.server 8080
```
เปิด `http://localhost:8080` ในเบราว์เซอร์

## การติดตั้งบนมือถือ
- **Android (Chrome):** จะมีแบนเนอร์ "ติดตั้ง" เด้งเอง หรือเมนู ⋮ → ติดตั้งแอป
- **iPhone (Safari):** ปุ่มแชร์ ⬆️ → เพิ่มลงในหน้าจอโฮม (iOS ไม่มีแบนเนอร์อัตโนมัติ)

## ข้อมูลเซฟที่ไหน
เก็บใน localStorage ของเบราว์เซอร์บนเครื่องนั้น — น้ำหนัก ท่าที่แก้ โปรแกรมที่เลือก อยู่ถาวรจนกว่าจะล้างข้อมูลเบราว์เซอร์ ใช้คนเดียว ไม่ส่งขึ้นเซิร์ฟเวอร์ไหน

## ฟีเจอร์
- 3 โปรแกรมสำเร็จรูป (5 วัน / 3 วัน / HIIT-only) สลับได้
- แก้/เพิ่ม/ลบท่าเองทุกท่า (ปุ่ม ✎ และ + เพิ่มท่า)
- ปุ่ม ↺ รีเซ็ตโปรแกรมกลับค่าเริ่มต้น
- ติ๊กท่าเสร็จ + progress bar (รีเซ็ตอัตโนมัติเมื่อขึ้นวันใหม่)
- Timer HIIT/plank/พักเซ็ต สลับ work/rest เอง มีเสียง + สั่น
- ติดตามน้ำหนัก + กราฟ trend เฉลี่ย 7 วัน
